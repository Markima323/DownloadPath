常见情况

为什么没有匹配到我正在浏览的网站？

来源页面、初始下载服务器和最终下载服务器可能是三个不同的网站。规则只检查你选择的地址字段；如果网站没有提供来源地址，扩展不会根据当前标签页猜测。请尝试针对实际下载服务器添加规则。

能保存到另一个盘符吗？

可以。为路径预设选择“绝对路径”，填写如 D:\Work 的目录，并安装上方的 Windows 辅助程序。文件先由 Chrome 下载，完成后自动移动；这与直接将 Chrome 的下载位置切换到另一盘符不同。

会覆盖已有文件吗？

相对子目录中的重名文件由 Chrome 自动添加编号，绝对路径移动时也会避开已有文件。未命中规则的下载继续沿用 Chrome 原有行为。

另存为、网页生成的文件和其他扩展有什么影响？

相对子目录模式中，主动选择“另存为”时以保存窗口中的选择为准。命中绝对路径规则后，扩展仍会在下载完成时尝试移动文件。网页生成的 blob 文件或未提供来源信息的下载，需要在目标网站实际验证；多个修改下载文件名的扩展也可能互相影响。

配置和下载记录会上传吗？

扩展不连接外部服务。预设、规则与最近记录保存在本机浏览器中；辅助程序仅处理本机文件。导出配置不包含下载记录。卸载扩展会删除其本机配置，辅助程序可单独卸载。
